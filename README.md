# CSS Color Markers Showcase
A sleek, modern, and visually striking frontend UI created specifically to practice and master advanced CSS Gradients, Box Shadows, and realistic 3D styling. This project showcases how dark themes, multi-format color models, and complex lighting depths can work together to build a stunning visual layout of realistic colored markers.

## Key Learning Focus
The main goal of this project was to learn and implement:
* **Advanced Gradients:** Using combinations of multi-layered `linear-gradient` to blend color tones and add realistic dimension to 2D shapes.
* **Complex Borders & Opacity:** Implementing custom double-layered borders using standard CSS `border` properties combined with alpha-channel opacity (`rgba`) for the marker sleeve.
* **Lighting & Glow Effects:** Designing custom neon-like glowing effects using `box-shadow` across varying color models including RGB, Hex, and HSL.

## Tech Stack Used
* **HTML5:** Structured semantic markup for the marker components (Cap, Sleeve, and Container).
* **CSS3:** Advanced gradient properties, custom drop shadows, inline-block layout alignment, and precise color-space styling.

## Features Shown in Code
* **3D Realism Design:** Stunning marker tubes rendered with deep shadows and highlighted center tones to mimic real-world lighting.
* **Multi-Format Color Palette:** Dynamic implementation of colors using traditional RGB, modern HSL, and clean Hex codes for tailored glowing effects.
* **Clean Layout Structure:** Soft border opacity mixed with centered margins to give the overall marker set a high contrast and balanced visual hierarchy.
